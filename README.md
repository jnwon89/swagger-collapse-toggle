# ⚡ Swagger Collapse Toggle Extension

## 📘 개요
Swagger Web UI 페이지에서 각 API 컨트롤러 섹션이 일괄 확장되어있어 스크롤 및 탐색이 불편하신가요?
본 확장 프로그램을 설치하여 버튼 클릭 한 번으로 간편하게 일괄 닫기/오픈 동작을 경험해보세요 :)
(브라우저의 상단바에 본 확장프로그램의 아이콘을 고정시켜두면 사용에 편리합니다!)
